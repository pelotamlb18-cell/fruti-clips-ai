# FRUTI CLIPS AI

Aplicación web para crear clips verticales 9:16 desde enlaces de YouTube.

## Archivos
- `app.py`: aplicación web.
- `requirements.txt`: dependencias de Python.
- `Dockerfile`: instala FFmpeg y ejecuta la aplicación.

## Importante
Esta primera versión crea segmentos distribuidos a lo largo del video; no selecciona momentos mediante inteligencia artificial ni añade subtítulos automáticos todavía. Utiliza únicamente videos propios o para los que tengas autorización. El alojamiento gratuito puede tener límites de tiempo, memoria y almacenamiento.
